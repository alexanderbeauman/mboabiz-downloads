# MboaBiz — téléchargements Android

Télécharge l’application Android depuis la page [Releases](https://github.com/alexanderbeauman/mboabiz-downloads/releases/latest).

## Version proposée

La version disponible est **MboaBiz 1.0.0 — version de test**. Il s’agit d’un APK debug, pas encore d’une version de production publiée sur Google Play.

## Important avant l’installation

- Cette version est signée avec une clé de test Android. Une future version Release pourra demander de désinstaller celle-ci avant installation.
- L’application se connecte au service MboaBiz en ligne. Les comptes et les données créés pendant l’essai peuvent donc être enregistrés sur le service. Pour le moment, n’utilise pas de données sensibles ou de véritables informations de clients.
- Android peut demander d’autoriser temporairement l’installation depuis le navigateur utilisé pour le téléchargement.

Télécharge le fichier APK dans la section **Assets** de la release, puis ouvre-le sur ton téléphone Android.
